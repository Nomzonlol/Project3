# Project3
This project focuses on the organization and visual analysis of large-scale transportation datasets for the Federal Highway Administration (FHWA). As transportation systems are vital to the economy and daily life, the FHWA collects extensive data to monitor performance and usage.
Our objective is to transform raw data from the National Household Travel Survey (NHTS) and the Next Generation Simulation (NGSIM) into clear, insightful visualizations that support informed decision-making for transportation planning. The details of the files in this project can be found above.
